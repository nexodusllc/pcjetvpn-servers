# pcjetvpn-servers

The public server list for the PCJETVPN Android app.

`servers.signed.json` is a **signed** file generated by `server/sign-server-list.sh` in the pcjetvpn repo.
It contains only public server information (locations, addresses, ports and server public keys).
The app downloads it from:

- `https://raw.githubusercontent.com/nexodusllc/pcjetvpn-servers/main/servers.signed.json`
- `https://cdn.jsdelivr.net/gh/nexodusllc/pcjetvpn-servers@main/servers.signed.json`

The app verifies the Ed25519 signature (format `pcjet-server-list/1`, key id `pcjet-sl-1`) with the public key
built into it, and refuses any list that is unsigned, modified, or older than the one it already has.
Don't edit the file by hand: change the list in pcjetvpn, bump `version`, re-sign, and replace the file here.
After pushing, purge the jsDelivr cache:
`https://purge.jsdelivr.net/gh/nexodusllc/pcjetvpn-servers@main/servers.signed.json`
